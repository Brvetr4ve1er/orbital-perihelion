# Sample CSVs

Drop these into the **Importer** button to test ingestion paths.

| File | Format |
| ---- | ------ |
| `inventory-raw.csv` | Unstructured French electronics inventory export |
| `pkos-products.csv` | Already-normalized PKOS export |

Programmatic samples live in `src/services/sample-data.ts` — the *Load sample data* command in the palette uses those.
