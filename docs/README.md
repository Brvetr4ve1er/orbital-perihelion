# Documentation Index

This folder reflects the application as it exists in code on 2026-04-27.

## Start Here

- `OVERVIEW.md` — What the product is, what is implemented, and what is not.
- `FUNCTIONING.md` — End-to-end runtime walkthrough: import, normalization, enrichment, persistence, analytics, and graph mode.
- `ACTIVE_ISSUES.md` — Current bug and code-quality register with severity, impact, evidence, and remediation notes.
- `INSIGHTS_AND_ISSUES.md` — Higher-level assessment of architectural strengths, weak assumptions, and operational risks.
- `CHANGELOG.md` — Historical engineering notes plus this documentation refresh.
- `module-audits/` — Per-module deep dives.

## Ground Rules For Future Docs Updates

1. Prefer code-verified statements over roadmap language.
2. If a feature is configurable in UI but not wired in code, document it as inactive.
3. When documenting bugs, include file references and observable impact.
4. When behavior differs between paths, document both paths explicitly.
